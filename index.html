Domain 1: Fundamentals of AI and ML

20%
1.1 · AI → ML → Deep Learning → Generative AI Hierarchy

These four terms form a strict subset hierarchy. Each is a specialization of the one above it.

🤖 Artificial Intelligence (AI) — Machines simulating human intelligence; rules, logic, or learning
⊂ Machine Learning (ML) — Learns patterns from data without explicit programming
⊂ Deep Learning (DL) — Multi-layer neural networks for complex patterns
⊂ Generative AI — Creates NEW content: text, images, audio, code
1.2 · Types of Machine Learning
Supervised Learning — Labeled Data
Type Goal Algorithms Metrics Example
Regression Predict continuous values Linear Regression, XGBoost RMSE, MAE, R² House prices, stock price
Classification Predict categories Logistic Regression, Decision Trees, Random Forest, SVM, KNN, XGBoost Accuracy, Precision, Recall, F1, AUC-ROC Spam detection, disease diagnosis
⚠️
Trap: Despite its name, Logistic Regression is a CLASSIFICATION algorithm, NOT regression. Linear Regression = regression tasks.
Unsupervised Learning — Unlabeled Data
Technique Algorithm(s) Use Case
Clustering K-Means, DBSCAN Customer segmentation, grouping similar items
Dimensionality Reduction PCA, SVD Reduce features while retaining information
Association Rule Learning Apriori Market basket analysis ("bought together")
Embeddings Object2Vec Recommendations, similarity search
⚠️
Traps: K-Means = CLUSTERING (unsupervised) — NOT classification. PCA = DIMENSIONALITY REDUCTION — NOT prediction.
Other Learning Types
🎮 Reinforcement Learning

Agent takes actions in environment, receives rewards/penalties. Algorithm: Q-Learning. Best for: robotics, game playing, industrial automation.

🔀 Semi-Supervised

Small labeled + large unlabeled data. Example: Sentiment Analysis when only some examples are labeled.

🤖 Self-Supervised

Model generates its own labels from input data (e.g., predicts missing parts). Used in LLM pre-training. Does NOT involve environment feedback.

📊 RLHF

Reinforcement Learning from Human Feedback. Human feedback included in reward function. Used to fine-tune LLMs. Key for SageMaker Ground Truth workflows.

1.3 · Neural Networks & Deep Learning
Component Description
Input Layer Receives raw data (features)
Hidden Layers Processes data; "deep" learning = many hidden layers
Output Layer Produces final prediction or classification
Weights & Biases Parameters adjusted during training to minimize error
Activation Function Introduces non-linearity; enables learning complex patterns
Forward Propagation Data flows forward through layers to produce output
Backpropagation Error flows backward; gradients computed to update weights
Gradient Descent Optimization algorithm to minimize loss by adjusting weights
Types of Neural Networks — Critical for Exam
Network Type Use Case Key Notes
FNN (Feedforward) General classification/regression Simplest type; data flows one direction
CNN (Convolutional) Image recognition, computer vision NOT for text/sequential data. ResNets = CNNs with skip connections
RNN (Recurrent) Sequential data, time series, video analysis Processes sequences in order; understands temporal relationships. Problem: vanishing gradients (solved by LSTMs)
Transformer Models NLP, text generation, translation Uses self-attention mechanism; foundation of GPT, BERT, Claude
GAN Realistic image generation, deepfakes Generator + Discriminator compete; adversarial training improves output
VAE (Variational Autoencoder) Image generation, data compression, anomaly detection Encodes to latent space, decodes to generate new data
Diffusion Models High-quality image & audio generation Adds noise then learns to reverse it. NOT for text analysis.
💡
Memory Tip: CNN = images. RNN = sequences/time series. Transformer = NLP/LLMs. BERT reads BIDIRECTIONALLY (translation/Q&A). GPT reads left-to-right (generation).
Key Training Concepts
Term Definition Exam Tip
Epoch One full pass through entire training dataset Too many epochs → overfitting
Batch Size Number of samples processed before weight update Smaller batch = more noise but faster convergence
Learning Rate Step size for gradient descent updates Too high = overshoots minimum. Too low = slow
Vanishing Gradient Gradients become too small; early layers stop learning Problem for RNNs; solved by LSTMs, ResNets
Exploding Gradient Gradients become too large — weights diverge Solved by gradient clipping
Regularization Technique to reduce model complexity and prevent overfitting Includes dropout, L1/L2
Dropout Randomly disables neurons during training A form of regularization
Early Stopping Stop training when validation performance stops improving Prevents overfitting
1.4 · Overfitting vs Underfitting (Bias-Variance)

⬆ Overfitting (High Variance)

  • Cause: Model too complex; memorizes noise
  • Symptom: Good on training, poor on test
  • Fixes: Simplify model, add more data, data augmentation, dropout, regularization, reduce epochs, early stopping

⬇ Underfitting (High Bias)

  • Cause: Model too simple; can't capture patterns
  • Symptom: Poor on both training AND test
  • Fixes: Add more features, increase model complexity, add epochs, more training data
1.5 · Model Evaluation Metrics
Classification Metrics
Metric Formula Use When
Accuracy Correct / Total Balanced datasets only. NOT for regression. NOT for imbalanced data.
Precision TP / (TP + FP) False positives are costly (e.g., spam filter)
Recall (Sensitivity) TP / (TP + FN) False negatives are costly (e.g., fraud, cancer screening)
F1 Score Harmonic mean of Precision & Recall Imbalanced datasets. NOT for LLM text generation.
AUC-ROC Area under ROC curve Binary classification performance overall
Specificity/TNR TN / (TN + FP) False positives very costly (e.g., kids' content filter)
Regression Metrics
Metric Description Key Note
RMSE Root Mean Squared Error — average prediction error in same units as target Sensitive to large errors/outliers. Lower = better.
MAE Mean Absolute Error — average absolute difference Less sensitive to outliers than RMSE. Lower = better.
R² (R-Squared) Proportion of variance explained by model (0–1, can be negative) NOT for classification. 1 = perfect fit; 0 = guessing average; negative = worse than average
MAPE Mean Absolute Percentage Error — average percentage error Common in forecasting. Lower = better.
💡
RMSE and MAE = regression. Accuracy and F1 = classification. AUC = binary classification. R-squared = regression ONLY.

2.2 · Large Language Models (LLMs)
Concept Detailed Description
Tokens Basic units of text (words, subwords, characters) that LLMs process. Input AND output are both measured in tokens. Tokenization does NOT capture semantic meaning on its own.
Vectors Numerical representations of tokens in high-dimensional space. Enables mathematical operations on text concepts.
Embeddings Pre-trained numerical vector representations that capture semantic meaning. Semantically similar words have vectors that are close together in vector space.
Context Window Maximum tokens (input + output combined) an LLM can process at once. Exceeding it causes earlier content to be truncated.
Latent Space The encoded knowledge and patterns learned by the LLM — represents internal understanding of language and concepts.
Hallucination Model confidently generates false/nonsensical output that sounds plausible but is not grounded in facts. Biggest risk in production GenAI.
💡
Tokenization ≠ Semantic meaning. Embeddings capture meaning. Context window = total (input + output) tokens the model can handle at once.
⚠️
Inference time depends on BOTH input sequence length AND output sequence length — not model size alone.
2.3 · Generative AI Model Types
Model Type How It Works Best For
Transformer Models Encoder-decoder with self-attention mechanisms. Predicts next element in a sequence. Text generation, NLP, LLMs (GPT, BERT, Claude)
Diffusion Models Adds noise to data then learns to reverse (denoise) it. Starts with random noise and iteratively cleans. High-quality image/audio generation. NOT text analysis.
GANs Generator creates fake data; Discriminator distinguishes real vs fake. Adversarial training improves both components. Realistic image generation, deepfakes, data augmentation
VAEs Encodes input to a latent space, then decodes by sampling from that latent space to generate new data. Image generation, data compression, anomaly detection
2.4 · Inference Parameters — Controls for LLM Output
Parameter What It Does Key Rule
Temperature Controls randomness of output. Higher = more creative/diverse. Lower = more focused/deterministic. 0.2 = deterministic. 1.0+ = creative. Most commonly tested.
Top-P (Nucleus Sampling) Token selected from smallest set whose cumulative probability reaches P. Higher P = less random. More adaptive than Top-K. Use for balanced diversity.
Top-K Limits token selection to top K most probable tokens only. Smaller K = safer/more predictable outputs.
Max Tokens Maximum tokens allowed in the response — caps response length. Controls output length and therefore cost.
CFG Scale Controls specificity of image generation. Higher = more specific/less random. Used for image generation models only.
Generation Steps For image models — more steps = higher quality image output. More steps = higher QUALITY, NOT more specificity. CFG Scale = specificity.
⚠️
Trap: Higher Temperature = MORE random/creative. LOWER Temperature = more focused/deterministic. More generation steps = higher QUALITY, not specificity — use CFG Scale for specificity.

2.6 · GenAI Limitations

Core Risks

  • Hallucination — generates false output confidently; biggest production risk
  • Toxicity — biased/harmful/offensive content without safeguards
  • Security — can generate phishing, deepfakes, malicious content
  • Explainability — "black box" decision-making

Operational Limitations

  • Cost — massive compute required
  • Data Dependency — quality depends on training data
  • Latency — high compute demand causes delays
  • Creativity — relies on existing patterns; lacks true originality
  • Regulation — IP and legal concerns unresolved

3.4 · FM Evaluation Metrics
Metric Full Name How It Works Best For
ROUGE Recall-Oriented Understudy for Gisting Evaluation Measures n-gram overlap between generated and reference text. Focuses on recall. Text summarization. Does NOT understand semantics.
BLEU Bilingual Evaluation Understudy Counts n-gram matches; penalizes outputs that are too short/long. Score 0–1. Machine translation quality.
BERTScore BERT-based semantic similarity Uses BERT embeddings to measure semantic similarity — understands "cat" ≈ "feline" Capturing semantic meaning. Smarter than ROUGE/BLEU.
Perplexity — Measures model's confidence in predicting next token. Lower = better. Language model quality evaluation
F1 Score — Harmonic mean of precision and recall Classification tasks. NOT for LLM text generation.
💡
ROUGE = summarization. BLEU = translation. BERTScore = semantic similarity (best for LLMs). F1 = classification ONLY. Perplexity = language model quality.
⚠️
ROUGE does NOT understand semantic meaning — it only measures word/n-gram overlap. Use BERTScore for semantic similarity.

4.1 · Core Responsible AI Principles
⚖️ Fairness

Ensure AI models are unbiased and do not discriminate based on protected characteristics (race, gender, age, religion, etc.)

🔍 Transparency

Make AI system behavior, decisions, and logic visible and understandable to stakeholders — developers, regulators, end-users

💡 Explainability

Provide clear interpretations of HOW AI makes decisions — enables accountability and trust

🛡️ Veracity & Robustness

AI systems operate reliably, consistently, and are resilient to failures and adversarial attacks

🔒 Privacy & Security

Safeguard privacy and security of data used by AI systems; handle personal information responsibly

📋 Governance

Clear frameworks, policies, and processes for responsible AI development and deployment

🦺 Safety

Identify and mitigate potential risks and unintended consequences

🎮 Controllability

Maintain appropriate human oversight over AI systems, especially in high-stakes decisions

4.2 · Types of AI/ML Bias
Bias Type Description
Reporting Bias Certain data points or outcomes are selectively reported/emphasized while others are omitted
Automation Bias Humans over-rely on automated systems without questioning their accuracy. Pertains to human behavior, NOT data.
Implicit Bias Unconscious attitudes or stereotypes that affect human decision-making — often embedded in training data
Selection Bias Training data not representative of the population the model will be used on
Confirmation Bias Model trained to confirm existing beliefs rather than find objective patterns

4.4 · Human Review in AI — Amazon A2I

Amazon Augmented AI (A2I) implements human review workflows for ML predictions. Integrates human judgment where model confidence is low.

  • Use cases: medical image labeling, content moderation review, financial document processing
  • RLHF: Reinforced Learning with Human Feedback — human feedback included in reward function to fine-tune LLMs
  • SageMaker Ground Truth: Human labeling service; uses Mechanical Turk; annotation consolidation combines multiple workers' labels for accuracy

5.2 · AI Attack Types & Mitigations
Attack Type Description Mitigation
Prompt Injection Attacker embeds hidden commands in input to override AI behavior Bedrock Guardrails, input validation, robust templates
Jailbreaking Crafted prompts bypass safety filters — make model generate harmful content Guardrails, rate limiting, user monitoring
Persona Switching Trick AI into adopting a malicious persona System-level constraints, monitoring
Exploiting Trust Generate convincing but false/manipulative information using AI Output monitoring, human review (A2I)
Template Extraction Probe AI to reveal hidden system prompt templates Cryptographic tokens, obfuscated templates
Data Poisoning Introduce corrupted data into training set to manipulate model behavior Data validation, source verification, data lineage
Model Inversion Reconstruct training data from model outputs — privacy breach Differential privacy, output filtering

1 · Amazon Bedrock AgentCore

GA — October 2025. A complete enterprise-grade platform for deploying and operating AI agents securely at scale. Works with ANY agentic framework (CrewAI, LangGraph, LlamaIndex, Strands, OpenAI Agents SDK) and ANY foundation model.

💡
Think of it as: The "infrastructure layer" for production AI agents — same way SageMaker Endpoint is the infrastructure layer for ML models.
AgentCore Service What It Does
AgentCore Runtime Serverless, scalable hosting. Longest-running workload on AWS. Supports VPC, PrivateLink, CloudFormation.
AgentCore Memory Persistent memory across sessions. Episodic Memory captures context, reasoning, actions, outcomes — agents learn from past interactions.
AgentCore Identity Authentication and authorization for agents across systems — agents can securely authenticate to APIs, databases, and services.
AgentCore Gateway Transforms APIs and data sources (including Bedrock Knowledge Bases) into agent-compatible tools with minimal code.
AgentCore Browser Scalable cloud-based browser execution for web automation. Used by Nova Act under the hood.
AgentCore Observability Full tracing and monitoring of agent interactions. Integrates with CloudWatch for metrics and alarms.
AgentCore Policy (Preview) Define agent behavior constraints in natural language (e.g., "never delete customer data"). Translated into Cedar policy language.

4 · Amazon Nova Forge

A program that gives enterprises access to Amazon Nova model training checkpoints so they can build custom frontier models called "Novellas." Fills the gap between fine-tuning and training from scratch.

Regular Fine-Tuning (Existing) Nova Forge (New)
Access Post-trained model weights only Pre-trained, mid-trained, or post-trained checkpoints
Risk Can cause "catastrophic forgetting" Mix proprietary + Nova-curated data — prevents forgetting
Phases Post-training phase only Pre-, mid-, and post-training
Cost Standard Bedrock/SageMaker pricing ~$100,000/year program; custom models deployed via Bedrock

8 · Bedrock Reinforcement Fine-Tuning (RFT)

A new model customization method using feedback-driven training rather than labeled example pairs. Delivers 66% average accuracy gains over base models without requiring large labeled datasets.

📌
RFT is essentially RLHF (Reinforcement Learning with Human Feedback) but simplified for enterprise use — no deep ML expertise required.

10 · MCP & A2A — Emerging Standards

MCP — Model Context Protocol

How agents connect to TOOLS and DATA. Open standard for connecting AI agents to data sources, tools, memory, and APIs. Supported by Strands, Kiro, Bedrock Agents. AWS has an AWS API MCP Server.

A2A — Agent2Agent Protocol

How agents connect to OTHER AGENTS. Standard for agents from different frameworks/vendors to communicate and coordinate. Enables multi-agent systems. Supported by AgentCore and Strands SDK.
